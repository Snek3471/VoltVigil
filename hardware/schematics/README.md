# Schematics

Place circuit diagram files in this folder.

Accepted formats:
- **PNG / JPEG** – exported schematic images
- **PDF** – printable schematics
- **KiCad** – `.sch` / `.kicad_sch` source files
- **Fritzing** – `.fzz` breadboard layout files

To add a schematic, commit the file to this folder and open a pull request into `dev`.
